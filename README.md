# 四季星空认星座（课堂教学增强版） · 记忆口诀 · 闪卡 · 错题重练

在"先学后测"认星座工具基础上，**从实际教学与记忆规律出发进一步增强**的课堂用具。
全天 76 个星座按**春、夏、秋、冬、拱极 + 南天**六个模块组织：四季与拱极模块
只收录北半球中纬度（北京约 40°N）可见的星座；北京看不到的典型南天星座单独
归入"南天星座"模块。

本版在原有"标注星图 + 两级测验 + 混合抽查"之上，新增六项教学功能：

1. **每星座一句记忆口诀**（押韵、抓最亮星与形状）；
2. **"怎么找"定位链**（从著名星群一步步找到目标星座）；
3. **亮星颜色标签**（颜色 = 表面温度，蓝白热、橙红冷）；
4. **闪卡速记**（正面星图、背面名字 + 口诀 + 亮星，3D 翻转）；
5. **错题重练 + 掌握度记录**（localStorage 本地保存，自动汇总薄弱星座）；
6. **观星小课堂**（星等、恒星颜色与温度、星座连线、天球旋转、中西星官、观星准备 6 篇）。

纯 HTML / CSS / JavaScript，**无需后端、无需联网，双击 `index.html` 即可使用**。

> 本版为在 `seasonal-constellations-plus/` 基础上的教学增强版，放在独立文件夹
> `seasonal-constellations-teach/`，原始文件夹保持不变。

## 一、教学流程（先学后测，建议节奏）

**建议课堂流程**：先上「观星小课堂」懂概念 → 用「闪卡」或进模块学口诀 →
模块测验检验 → 「错题重练」消灭薄弱点 → 「混合抽查」综合验收。

1. **首页**：顶部是**学习进度总览**（学习进度 / 已掌握数量）；下方是六个模块、
   「闪卡速记」「观星小课堂」两张工具卡，以及「混合随机抽查」。
2. **季节页**：本季星空概览、定位口诀（如夏季大三角、冬季六边形、南十字指南天极）、
   星座卡片列表；每张卡片右上角有**掌握度标签**（未学习 / 已学习 / 需巩固 / 已掌握）。
3. **学习页**（每个星座）：
   - 顶部**记忆口诀横幅**（如猎户"腰带三星直又亮，红肩蓝脚好认郎"）；
   - 带**星座连线 + 中文星名**的完整星图，金圈标出"必认亮星"；
   - 形状、辨识要点、**怎么找（定位链）**、拓展讲解、最佳观测时间；
   - "必认亮星"卡片带**颜色圆点 + 星等 + 颜色名**（如"参宿七 0.18 等 · 蓝白色"），
     点击可在图上定位并查看科普（标题带颜色，附温度提示）。
4. **测验**（每个星座两关，自动判分）：
   - **第 1 关 · 认星座**：看星点与连线，从 4 个同季节候选中选出星座名；
   - **第 2 关 · 点亮亮星**：给出亮星名，在星图上点出对应星点；
   - 答后即时反馈：答对绿环，答错红环并以金环揭示正确星，附讲解。
5. **成绩单**：按星座列出两关对错与总分，底部有**「错题重练」**按钮（只抽答错过的星座）。

> 测验页顶部有"显示 / 隐藏星座连线"开关：学习时显示连线入门，
> 测验时可关闭（最接近真实观星、只看星点）。

## 二、六项教学增强详解

### 1. 记忆口诀（每星座一句）

为全部 76 个星座编写一句押韵口诀，抓**最亮星 + 形状 + 相邻关系**，便于学生记忆。
学习页顶部横幅展示，认星座答错时也会带出口诀。代表口诀：

| 星座 | 口诀 |
| --- | --- |
| 猎户座 | 腰带三星直又亮，红肩蓝脚好认郎 |
| 大犬座 | 腰带东南找天狼，全天最亮放光芒 |
| 天蝎座 | 红心宿二蝎心亮，带钩长尾最逼真 |
| 飞马座 | 四颗二等大四方，秋季找星它为纲 |
| 南十字 | 四亮星成小十字，长轴四倍指南极 |
| 小熊座 | 小北斗柄北极星，四季旋转它不动 |

### 2. "怎么找"定位链

每个星座给出**从著名星群出发、一步步定位**的方法，教学生"在真实天空中如何找到它"，
而不只是记住一张图。例如：

- 猎户座：冬夜南天找三颗等距排成一线的亮星（腰带）；四颗亮星组成四角，
  左肩红色参宿四、右脚蓝白参宿七。
- 大犬座：从猎户腰带三星向东南方向延长，遇到的第一颗极亮星就是天狼，全天最亮。
- 狮子座：找到北斗斗柄，沿斗柄弧线向东南"春夜大曲线"，先到牧夫大角，再到室女角宿一；
  狮子在北斗斗口下方，镰刀反写问号。

### 3. 亮星颜色标签（颜色 = 温度）

恒星颜色由**表面温度**决定：蓝白星最热、橙红星较冷。本版在亮星卡片上用
**颜色圆点 + 颜色名**直接标注，并在科普介绍中补充温度提示，让学生建立
"颜色 ↔ 温度"的直观联系。颜色分级（按 B−V 色指数）：

| 色指数 B−V | 颜色 | 代表 |
| --- | --- | --- |
| < 0.3 | 蓝白色（最热） | 参宿七、轩辕十四、角宿一 |
| 0.3–0.6 | 白色 | 天狼、织女、北河三附近 |
| 0.6–0.9 | 黄白色 | 五车二、北落师门 |
| 0.9–1.2 | 淡黄色 | 南门二、南河三 |
| 1.2–1.6 | 橙色 | 参宿四、毕宿五、心宿二附近 |
| ≥ 1.6 | 红橙色（最冷） | 心宿二、参宿四（实际偏红） |

> 教学要点：猎户"红肩蓝脚"——左肩参宿四是红超巨星（橙红、偏冷），
> 右脚参宿七是蓝超巨星（蓝白、很热），颜色对比一眼可辨。

### 4. 闪卡速记

首页「闪卡速记」进入，适合**课前 5 分钟快速过**：

- **配置**：勾选要复习的模块（可多选，含南天），可选随机打乱、正面先隐藏连线（只看星点）；
- **翻卡**：正面是星图（先自己想名字与口诀），点击卡片（或按空格）**3D 翻转**看背面；
- **背面**：星座名 + 记忆口诀 + 必认亮星（带颜色）；
- 支持上一张 / 下一张按钮，键盘 **← / → 切换、空格翻面**。

### 5. 错题重练 + 掌握度记录

- **本地记录**：学习与答题结果通过 `localStorage` 保存（键 `constellation_teach_progress_v1`），
  刷新或关闭页面后进度不丢。
- **掌握度四级**：
  - **未学习**（灰）：还没打开过学习页；
  - **已学习**（蓝）：已打开学习页，但还没测或没测全；
  - **需巩固**（橙）：最近一次测验有错题；
  - **已掌握**（绿）：最近一次两关全部答对。
- **错题重练**：模块测验、混合抽查的成绩单都有「错题重练」按钮，
  一键只抽答错过的星座重新测，做对后自动转为"已掌握"。

### 6. 观星小课堂

首页「观星小课堂」进入，**认星座前先懂 6 个基础概念**：

1. **星等**：数字越小星越亮，1 等比 6 等亮 100 倍，天狼约 −1.4 等；
2. **恒星颜色与温度**：蓝白最热、橙红最"冷"；
3. **星座连线**：连线是人为帮助记忆，真实天空没有线，要练只看星点；
4. **天球旋转**：星星东升西落、绕北极星转，故不同季节夜空不同；
5. **中西两套星图**：中国三垣四象二十八宿 vs 西方 88 星座；
6. **观星准备**：选晴夜、避灯光、让眼睛暗适应、带红光手电与星图。

## 三、模块分组与覆盖范围

共 **76 个星座**，划分为 6 个模块：

| 模块 | 数量 | 代表星座 |
| --- | --- | --- |
| 拱极·全年 | 5 | 大熊（北斗）、小熊（北极星）、仙后、仙王、天龙 |
| 春季（3–5 月） | 10 | 狮子座、牧夫座、室女座、长蛇、乌鸦、巨爵…… |
| 夏季（6–8 月） | 13 | 天琴（织女）、天鹅、天鹰（牛郎）、天蝎、人马、海豚…… |
| 秋季（9–11 月） | 12 | 飞马（秋季四边形）、仙女、英仙、南鱼…… |
| 冬季（12–2 月） | 13 | 猎户、大犬（天狼）、小犬、双子、金牛、御夫…… |
| **南天星座** | **23** | 南十字、半人马（南门二）、船底（老人星）、南三角、孔雀、天鹤、凤凰、船帆、杜鹃、剑鱼、南极…… |

南天板块以**中心赤纬 < −40°**（北京最高高度不足约 10°、实际难以观测）为判据，
共 23 个星座；边界星座（天鸽、船尾、罗盘、天蝎、人马、波江）保留在四季。

**必认亮星**：每个星座自动取视星等 ≤3.0 的最亮星（最多 3 颗），暗星座取最亮 1 颗；
四季模块自动排除赤纬 < −45°、北京不可见的星，南天模块保留完整南天亮星。

## 四、混合随机抽查（10 题，跨四季与拱极）

首页底部「混合随机抽查」提供**跨模块综合测验**：

- 题量固定 10 题，"认星座"与"点亮星"两种题型各约 5 题、随机打乱；
- 题目池为拱极 + 春 + 夏 + 秋 + 冬 = **53 个星座，不含南天**；
- 可勾选季节、可勾选「⭐ 优先考查 21 颗一等亮星所在星座」（视星等 ≤1.4）；
- 成绩单支持**「错题重练」**、再来一组（同样侧重）、重新设置侧重。

## 六、运行

**最简单**：双击 `index.html`，用任意现代浏览器打开即可。

如个别浏览器对本地文件有限制，可在本目录起静态服务器：

```bash
python -m http.server 8766
# 访问 http://127.0.0.1:8766/index.html
```

> 进度数据保存在浏览器本地（localStorage）。如需全班从零开始，
> 在浏览器控制台执行 `localStorage.removeItem('constellation_teach_progress_v1')` 即可清空。

## 七、技术说明

- 星图引擎（立体 / 北极极投影、星点大小、B−V 星色、光晕、网格、标签、点击命中）
  与原版一致；本版在其上叠加教学内容与进度记录。
- 闪卡 3D 翻转采用 `transform-style: preserve-3d` + `backface-visibility: hidden`，
  并以 `visibility` 切换做双保险，兼容个别浏览器首次合成时背面穿透的问题。
- 天文数据移植自 AstroGames（Hipparcos 星表、76 星座边界 / 连线 / 命名星），
  仅供课堂教学使用。
